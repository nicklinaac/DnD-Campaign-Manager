# 🧙 D&D Campaign Manager

A fun Python-based CLI tool for managing Dungeons & Dragons characters, campaigns, and dice rolls.

## Features

- Create and store characters (name, race, class, stats, inventory)
- Load and list saved characters
- Roll any type of dice (d20, d6, etc.)
- JSON-based local data storage
- Clean OOP design

## Getting Started

```bash
git clone https://github.com/nicklinaac/DnD-Campaign-Manager
cd dnd-manager
python main.py
